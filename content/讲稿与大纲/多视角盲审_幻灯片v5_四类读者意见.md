# 多视角盲审：幻灯片 v5 的四类读者意见

> 审读对象：`quartz/static/slides/after-the-machines-plain-v5.md` 及解释卡所在的同名 HTML。  
> 审读方式：四个子代理均以 `fork_turns="none"` 启动，没有继承本对话。它们只被允许阅读根目录 `AGENT_PERSONAS.md`、目标幻灯片 Markdown 和必要的 HTML；明确禁止阅读既往审读报告、材料整合稿、交接文档和其他代理输出。  
> 状态：四个代理均完成独立只读审读；没有修改幻灯片。

## 一、盲审仍然出现的共同判断

### 1. 三地区历史是目前最稳定的主体骨架

四个视角都肯定：

- 诺丁汉把机器、产品规格、工价、行业调查和规制尝试连在一起；
- 约克郡把住宅、磨坊、厂主、法庭和地方记忆连在一起；
- 兰开夏保留了性别排除、机器辩护和劳动者内部技术分歧；
- 共享 “Ludd” 名称没有被误写成已获证实的全国总部；
- 同情劳动者没有导致证据标准下降。

普通观众认为自己能够复述三个判断：

1. 争议不只是机器，而是机器改变的工价、技能、规则和权力；
2. 三地没有形成已获证实的统一全国组织；
3. 策略性、组织性与正当性不是同一回事。

### 2. 第 36—53 页仍被独立识别为主要断层

四个盲审代理没有收到任何关于理论部分的提示，却都指出：

- 三地历史在第 35 页已经形成阶段性结论；
- 此后连续十八页进入另一套理论课程；
- 过程链、四道门槛、五次力量转换等框架竞争同一记忆位置；
- 大量理论家各承担一两个概念句，既增加认知负担，也可能压缩思想差异；
- 历史材料逐渐退到背景，身体、空间和档案声音减少。

这说明“理论区段的组织方式需要调整”是较稳健的诊断，不只是上轮问题提示造成的确认偏误。

盲审并不一致主张删掉理论。更准确的共识是：

- 主体只保留一套主要分析框架；
- 理论问题持续回扣三地材料；
- 人名谱系和复杂分歧进入备用讨论；
- 明确哪些是作者综合模型，而不是历史已经验证的定律。

### 3. 历史、理论和 AI 的讲述契约不够清楚

普通观众、编辑和艺术家均认为当前内容像三种体例连续出现：

```text
卢德运动地区史
→ 阶级与组织理论课
→ AI 劳动治理或公共调查工作坊
```

盲审普通观众并不要求用 AI 焦虑替代历史开场，但希望开头尽早说明：

> 为什么今天值得听，以及历史、理论和当代问题将怎样连接。

编辑提出两种可选定位：

- 公共历史主讲：历史为主体，理论压缩，AI 成为短后记；
- 历史—AI 劳动政治主讲：修改副标题，并在开场明确三段议程。

### 4. 证据纪律是优点，但表达层级仍需调整

盲审与上轮有一个重要差别：它们没有简单要求把证据边界全部移入 hover。

四方共同认可：

- Sykes 单一受害方证词；
- Booth 同期材料与晚出记忆；
- Westhoughton 控罪与陪审团裁断；
- 约克处决者不同案件类别；
- 匿名就业信与无法确认的作者身份；
- “AI 不是十九世纪织机的重演”

这些限定构成整场可信度和再现伦理的基础。

更合适的分层是：

| 信息 | 所在位置 |
|---|---|
| 会改变观众伦理判断的状态，例如控方证词、晚出记忆、假想案例 | 正面可见 |
| 较完整原文、译文、档案号、版本差异 | hover |
| 完整案件结构、反证、理论谱系和纠谬材料 | 备用页 |

需要减少的是连续否定式修辞和多次重复审计，而不是证据边界本身。

### 5. AI 部分需要明确标注为作者方案

盲审代理都肯定结尾“知情、决定、成本、收益、纠错”五问，但认为：

- 六层关系、最低共同要求、暂停权和制度条款属于作者的分析与规范提案；
- 它们不是卢德史自然推出的唯一结论；
- 也不是所有法域都已经存在的权利；
- 若完整保留，应补充当代劳动、算法管理、工会谈判或供应链案例。

## 二、四个干净上下文 persona 的独立意见

### Agent 1：人文社科分享会普通观众

#### 总体判断

历史部分大体能够跟上，最大困难在历史之后：理论人物、概念和多套模型快速累积，听众可能在到达 AI 前耗尽注意力。

#### 新提出的重点

1. **“为什么今天值得听”出现得太晚。**  
   开场解释了为何要纠正卢德标签，却没有尽早说明长篇历史最终帮助判断什么现实问题。

2. **早期三地空间感不足。**  
   开场英国地图注明不标三个纺织区；地名 hover 不能替代现场所有人都能看到的三地总图。

3. **开放问题累积过多。**  
   多张页面以“哪一种解释更对”收束，却不立即给出本讲暂定判断。听众难以判断哪些问题留给讨论，哪些问题作者已有答案。

4. **数字框架过多。**  
   三种地方政治、三场争论、四道门槛、五次转换、六层关系等不断变化，削弱了记忆锚点。

#### 偏好

盲审普通观众更愿意保留结尾五问，并用它们反向取舍前面的框架；也不希望为了“现实感”而让 AI 新闻取代历史开场。

### Agent 2：开放而有原则的马列毛左派读者

#### 总体判断

幻灯片已经明显超出“卢德派其实不反技术”的翻案，较好呈现生产关系、群众能动性、内部排除和国家镇压。

它提出的主要批评并非“理论太多”，而是理论层级仍不够清楚：

- 资本积累与竞争逻辑没有成为统摄关系；
- 国家容易被写成中性的双面制度接口；
- 组织讨论重信息、代表和纠错程序，较少处理政治路线与群众领导；
- AI 部分缺少全球资本主义、平台垄断和帝国主义供应链；
- 最低改革与所有权转变之间的张力不足。

#### 重要修正

“五次没有完成的力量转换”有启发，但可能把历史运动放到后见之明的组织能力清单上评分。失败不仅是劳动者没有完成转换，也包括统治阶级主动阻止转换。

#### 反方边界

它同时警告：若把国家直接写成资本家的简单工具，会忽略陪审团无罪裁断、法律程序和国家内部矛盾；若把成熟政党理论反推给卢德运动，也会造成时代错置。

### Agent 3：社会科学出版社编辑

#### 总体判断

当前不能只靠局部润色公开发表，应先确定体例和篇幅，再做证据、引注与许可审校。

#### 必须核查的问题

1. **第 29 页匿名纺纱工信档号不一致。**

   - 正文：`TNA HO 40/1`
   - 备用页：`TNA HO 40/1/1`
   - HTML 卡片：`TNA HO 42/120；Binfield，N1`

2. **第 13 页并存材料的结论可能过强。**  
   三份文本能说明同一时点存在公开协商、加价承诺和匿名威胁；不能单独证明同一组织结合协商与强制，也不宜写成彻底否定所有阶段性解释。

3. **约克和 Westhoughton 精确判决数字需要页码与汇总口径。**

4. **四道门槛、五次转换等模型需要标为“本讲分析框架”，降低“决定”等因果措辞。**

5. **理论引注、中文译文版本和 Binfield 文献编号需要统一。**

6. **英国国家档案馆截图和 NASA 洁净室图需要核查复用依据与视觉准确性。**

#### 结构建议

- 前十页标签与解释铺垫可压缩；
- 约克郡案例偏多，Horsfall、Mellor、Booth 可择一部分转入备用；
- 第 34、35 页连续总结可合并；
- 结尾在进入五问前应直接回答“卢德运动究竟是什么”。

### Agent 4：关注劳工与社会公正的艺术家

#### 总体判断

文字在伦理上克制，视觉上却仍让挥锤者比劳动过程和国家暴力更容易被记住；理论部分又让身体、声音和空间退场。

#### 重要新意见

1. **工人暴力有动作图像，国家暴力主要是文字和数字。**  
   封面挥锤形象具有强记忆性，军队、法庭、处决和档案分类却主要以表格出现，形成感知不对称。

2. **法律档案可能在形式上再次支配死者。**  
   处决者容易只剩“3 人、9 人、5 人”。可核实的姓名、职业、年龄或亲属关系应获得一次克制呈现；无法恢复的部分标为档案沉默。

3. **Sykes 场景只能通过受害方眼睛进入。**  
   若无行动者第一人称材料，应让这种缺失本身可见，而不是用推测补齐。

4. **AI 图库人物仍是无声职业类型。**  
   更合适的视觉对象是任务记录、错误日志、扫描路径、标注界面、申诉流程或实际共同绘图。

5. **“劳动影响图”应真正画出来。**  
   当前仍是一页关于图的文字说明；若现场逐步生成，它可以把 AI 部分从作者宣讲转为公共调查工具。

#### 视觉建议

- 建立“物件—动作—规则”主线；
- 以稳定视觉语法区分工人信件、受害方证词、控罪文本、晚出记忆和学者解释；
- 关键年代、图库性质和非现场状态不能只放在小字图注；
- 不需要通过暴力音效、仿旧或戏剧化转场增加冲击。

## 三、盲审与上轮带上下文审读的比较

| 上轮集中意见 | 干净上下文结果 | 当前评价 |
|---|---|---|
| 第 36—53 页理论区过长 | 四方再次独立发现 | 稳健诊断 |
| 一场分享叠加三种体例 | 普通观众与编辑再次明确提出 | 稳健诊断 |
| 劳动过程缺少实感 | 普通观众、左翼读者和艺术家仍提出，但不再是所有报告的唯一中心 | 有效问题，但不能支配全部修改 |
| 证据边界应大量移入 hover | 盲审更强调关键伦理状态必须正面可见 | 上轮处方需要修正 |
| AI 应缩成后记 | 盲审认为取决于讲座定位；左翼读者反而要求补所有权与帝国主义 | 属于作者选择，不是统一结论 |
| 第 29 页档号不一致 | 盲审编辑再次独立发现，并发现三种写法 | 已确认硬问题 |
| 女性劳动缺少主体位置 | 左翼读者和艺术家再次提出 | 稳健伦理问题，但不能用虚构声音补齐 |
| 正文、hover、备用重复 | 盲审较少逐项统计，但仍要求静态替代和分层 | 有效编辑问题 |

盲审说明：上轮并非所有结论都只是提示造成的确认偏误，但“把理论大幅删除”“把证据边界尽量藏进 hover”等具体处方确实过于一致、过于提前。

## 四、建议先处理的事项

### 第一优先：硬问题

1. 查清第 29 页档号；
2. 复核第 13 页并存材料的推论强度；
3. 补约克、Westhoughton 判决数字的页码和口径；
4. 标明理论引文版本、自译状态和作者模型；
5. 核查国家档案馆截图、NASA 图像和 hover 地图许可。

### 第二优先：讲述契约

1. 明确活动时长和首要受众；
2. 选择公共历史主讲，或明确改为“历史—AI 劳动政治”；
3. 在开场给出三地总图和一条现实问题线索；
4. 在结尾五问之前直接回答“卢德运动是什么”。

### 第三优先：结构

1. 只保留一套主体理论框架；
2. 合并第 34、35 页及其他重复总结；
3. 调整约克郡案例密度；
4. 减少连续开放反问；
5. 让 AI 方案明确署名为作者的讨论框架。

### 第四优先：感知与材料分层

1. 用局部、可核实的劳动动作和物件增加实感；
2. 让国家强制也获得物质形态；
3. 建立证据类型的稳定视觉语法；
4. 真正画出劳动影响图；
5. 为无 hover 的录屏、PDF 和打印版本准备静态来源层。

## 五、本轮不据盲审立即修改的事项

- 不自动把理论压到固定页数；
- 不自动把 AI 缩成两页或拆成另一场分享；
- 不把所有证据限定移入 hover；
- 不在技术史材料不足时补画完整生产链；
- 不用虚构工人声音或图库人物代替档案沉默；
- 不把任何 persona 的政治或审美偏好当作唯一编辑标准。
