### 1.1 当前中心判断

全讲不是在回答“应该支持还是反对机器”，而是在训练一种辨认技术政治的方法：

- 看见劳动过程，而不只看机器物件；
- 追踪收益和成本，而不只问总体效率；
- 检验共同利益中的排除，而不预设统一主体；
- 寻找现实依赖和组织能力，而不迷信行动外形；
- 把胜利写成可执行、可复议、可纠正的公共规则。

最后一句固定为：

> 机器破坏属于过去；围绕生产决定权的政治没有结束。

视觉设计应帮助这条线索逐步显现，不能让“复古机器”“愤怒工人”或“AI 科技感”取代它。

## 4. 下一阶段的视觉工作目标

分享面向对卢德运动和英国劳动史缺乏专业背景的普通听众。视觉系统需要完成四项任务：

1. 帮助观众迅速区分三个地区及其不同劳动世界；
2. 让工价、物件、劳动动作、生产空间和原始文件具有实感；
3. 把理论之间的关系表现为不同解释和不同风险，而不是理论家名单；
4. 让 AI 尾声看起来是历史问题的当代转译，而不是突然切换为企业科技演示。

建议的总体气质：

- 克制的档案感与印刷物感；
- 有历史材料的质感，但不做仿古舞台布景；
- 避免企业咨询报告、UI 卡片墙、霓虹科技和“蒸汽朋克”；
- 不把每页做成独立海报，要保持连续讲述的节奏；
- 色彩服务于地区、证据类型和理论关系，不作纯装饰。

一个可尝试但尚未由用户最终确认的方向：

- 基础色：暖白或浅纸色、炭黑；
- 诺丁汉：低饱和砖红或棕红；
- 约克郡：低饱和靛蓝或钢蓝；
- 兰开夏：低饱和赭黄或深橙；
- 三地比较与理论区：回到中性色，以少量强调色显示关系；
- AI 尾声：使用较冷的灰蓝，但继续保留前文的纸色、边线和排版逻辑。

不要一开始全稿铺开。先用代表页检验色彩、字体、表格、引文、图片和页码系统是否协调。

## 5. 推荐先做的代表页

### 5.1 第8页：一双袜子的争议，藏在八便士里

检验目标：

- 大数字和算式怎样成为视觉中心；
- `8 jacks → 2d → 10d → 8d` 是否可以一眼理解；
- 技术术语的悬停提示是否仍然清楚；
- 来源和证据限制能否留在页上但不过度抢占注意力。

不应把这页重新做成普通段落加配图。

### 5.2 第16或18页：住宅空间与 Rawfolds

检验目标：

- 如何表达门、住宅、家人、蜡烛、剪具、机器和设防磨坊；
- 如何让空间关系可见；
- 如何使用历史图、地点照片或简单结构图，而不制造未经证实的写实场景。

如使用图示，应明确它是解释性布局，不是现场复原。

### 5.3 第31或33页：从三地进入理论

检验目标：

- 五项政治转换怎样成为清楚的视觉主轴；
- 理论不是突然出现的作者名单，而是回答历史断裂的工具；
- 历史区与理论区之间应有明显但连续的视觉转场。

### 5.4 第49或50页：组织形式与力量循环

检验目标：

- 大表格如何减少“Excel感”；
- 五种组织形式和五种力量转换怎样形成可比较的视觉层级；
- 不依赖缩小字号容纳信息；
- 理论家悬停卡仍然可以触发。

### 5.5 第51页：AI 当代尾声

检验目标：

- 历史与当代之间有视觉连续性；
- 具体部署场景比抽象“AI感”更醒目；
- 数据中心照片不应主导叙事；
- 页面不能滑向常见企业科技蓝和发光线路风格。

## 6. 全稿值得优先改善的页面类型

### 6.1 原始材料页

包括第8—10、12—14、16、23、25、26、32、34、38、48页。

建议：

- 优先寻找或制作档案局部、原始排版、手写／印刷文本局部；
- 使用一小段清楚放大的原文，不把整页不可读的扫描件当背景；
- 需要强调时只标一至两个词或数字；
- 正面保留核心动作或判断，较完整原文继续放在 hover 卡；
- 原始材料、现代转录和主讲人的解释必须有视觉区分。

### 6.2 劳动过程与空间页

包括第6、8、9、11、16—18、23页。

建议：

- 优先使用物件、动作、生产空间和工作分配关系；
- 可用单幅时期图像、局部放大、空间剖面或简洁流程；
- 不制造“完整流水线”，因为史料并不总能支持；
- 机器图需要说明年代、用途和是否只是解释性图像。

### 6.3 三地比较页

包括第27—31页。

建议：

- 建立稳定的三地区分符号或色彩；
- 同一地区在不同页使用一致的视觉标识；
- 不把地区比较做成三个互不相干的卡片；
- 重点表现对象、能力、失败位置和排除边界之间的关系。

### 6.4 理论页

包括第33—50页。

建议：

- 不要为每位理论家正面放肖像；
- 人物简介继续留在 hover 卡；
- 正面应展示理论之间的分歧、补充和风险；
- 优先使用关系图、过程链、对照轴、反馈循环和少量强调词；
- 同一理论组形成一致版式，但相邻页面不要机械重复；
- 第49、50页是整个理论段的收束，必须比普通表格更有结构感。

### 6.5 AI 尾声

包括第51—55页。

建议：

- 第51页使用具体部署场景建立入口；
- 第52页突出任务、隐性知识、异常处理和责任转移；
- 第53、54页的五项能力应形成稳定的视觉编码；
- 第55页回收开场视觉母题，不要用“谢谢”或新问题结束。

## 7. 图片补充规则

### 7.1 优先顺序

1. 当前资产目录中已有且适合的图像；
2. 工作区事实核查材料能够定位的档案图、书影和原始文书；
3. 英国国家档案馆、British Library、Wikimedia Commons、博物馆和大学馆藏等可追溯来源；
4. 必要时使用现代地点照片或现代纪念物，但必须明确标注；
5. 当代 AI 页可以使用可靠图库照片，但应避免虚构的“AI大脑”“机器人握手”等陈词滥调。

### 7.2 不要做

- 不用生成式图片伪造历史现场；
- 不用电影剧照、游戏美术或无来源插画充当史实；
- 不因“看起来像十九世纪”就忽略图像实际年代；
- 不把无法阅读的整页档案扫描件当装饰背景；
- 不为填满页面而添加与论证无关的图片；
- 不在多个页面反复使用同一幅非背景图片；
- 不裁掉物件、人物动作或文书中承担证据意义的部分。

### 7.3 来源说明

每张正面图片至少记录：

- 作者或机构；
- 标题或对象；
- 年代；
- 馆藏／来源链接；
- 许可状态；
- 是否为晚出图像、现代地点照片或解释性图示。

幻灯片正面使用简短图注；完整来源可以放进图注链接、备用页或相邻来源说明。不要删除当前已有的证据限制。

## 8. 必须保留的悬停卡机制

HTML 中已经实现三类卡片：

1. 普通术语／人物解释卡；
2. `source-excerpt` 原始材料卡；
3. `map-only` 地名定位卡。

当前机制包括：

- 鼠标 hover；
- 键盘 focus；
- 普通卡宽度约 380px；
- 史料卡宽度约 520px；
- 卡片高度受限；
- 正文区域允许内部滚动；
- 地图卡只显示英国范围内的位置图；
- 手机端有单独尺寸限制；
- 标题过长时最多两行；
- 卡片自动避开视口边缘。

视觉重构时可以调整卡片的颜色、边线、阴影和字体，使其进入新的视觉系统，但不要破坏：

- 卡片滚动；
- 键盘可访问性；
- `source` 与普通说明的差异；
- 地图卡只显示地图；
- 第一次出现的陌生地名才加地图；
- “英国”等无需解释的地名不加卡；
- 人物卡仍保持“一句百科身份＋一句与本讲主题的关系”。

特别注意：理论页表格中的考茨基、列宁、葛兰西已接入现有卡片键值。重排表格时不要把这些触发器变成纯文本。

## 9. 当前 HTML 布局机制

v6 HTML 当前包含：

- `roomyPages`、`densePages`、`compactPages` 三组页码绑定；
- `layout-visual-left`、`layout-visual-right`；
- `visual-stack`、`slide-figure`、`visual-copy`；
- 自动生成 `slide-page-number`；
- 第8—31页自动生成地区标签；
- 图片 lazy loading；
- 自动识别“来源：”段落并缩小；
- 将每页标题与正文包装为 `slide-body`；
- 悬停卡目录和定位脚本。

视觉阶段允许调整或重构这些布局，但必须注意：

- 页码绑定是按当前页序写死的；
- 新增、删除或重排页面会使密度 class、地区标签和页码相关逻辑错位；
- 当前内容阶段不授权增删主讲页；
- 如改变 Markdown 缓存内容，应同步更新 HTML 中 `data-markdown` 的查询版本；
- 不要只改 Markdown 而忘记浏览器可能继续读取缓存版本。

如果改成新的 CSS 文件，应确保本地静态路径和 Quartz 构建都能复制该文件。若没有充分理由，保留现有 HTML 内联 CSS 是风险更低的方案。

## 10. 窄屏现状

390×844 检查结果：

- 页面没有被裁切；
- 第49页组织形式表格和第51页 AI 场景仍在画布内；
- 悬停卡具有手机尺寸规则；
- 但 Reveal 当前会把整张 1600×900 幻灯片缩小到手机宽度，正文字号非常小。

因此“没有溢出”不等于“窄屏可读”。

下一轮需要明确选择：

- 如果手机只用于快速预览，可以维持完整画布缩放，但应保证触发器可点、图片不糊；
- 如果希望手机成为实际阅读方式，应为 `reveal-scroll` 或窄屏建立真正的纵向排版，而不是单纯缩小整张画布。

不要在没有实际浏览器验证时声称手机布局已经完成。

## 11. 推荐实施顺序

### 阶段一：建立视觉语言

1. 记录当前桌面和窄屏截图；
2. 选择字体、基础色、地区色和证据类型样式；
3. 完成第8、31／33、49／50、51页代表稿；
4. 检查标题、正文、表格、引文、图注、页码、地区标签和 hover 卡是否属于同一视觉系统。

### 阶段二：重排主讲页

1. 先处理开场与三地历史；
2. 再处理理论区；
3. 最后处理 AI 与结语；
4. 每处理一组就检查页面溢出和相邻页节奏；
5. 不要等到全部完成后才发现字体或图片比例不适合。

### 阶段三：补充图片

1. 列出真正需要图像的页面；
2. 先复用现有资产；
3. 再检索缺少的档案材料、劳动物件和地点图；
4. 下载后统一转换为适合浏览器的 WebP／PNG／SVG；
5. 保留来源记录和原始链接；
6. 检查裁切、分辨率、色彩和图注。

### 阶段四：备用页与交互

1. 使56—70页至少继承新版字体、色彩、表格和图注；
2. 逐一触发地图、人物、术语和史料卡；
3. 检查长史料卡滚动；
4. 检查键盘 focus；
5. 检查卡片不会被图片、表格或 Reveal 控件遮挡。

## 12. 验收标准
