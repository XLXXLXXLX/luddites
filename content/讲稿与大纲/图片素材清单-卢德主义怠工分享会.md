# 图片素材清单：卢德主义、怠工与社会转型

说明：

- 这份清单按讲稿结构整理，优先放 `Wikipedia / Wikimedia Commons / 档案馆 / 公共图库` 这类相对容易继续追到原图的页面。
- `页面链接` 不一定是原图直链，但通常页面内就有图，点进去能继续到原图或文件页。
- 当我没找到合适的稳定图片页时，给出 `搜索关键词`，方便你自己去图搜或换中文平台搜。
- 当代新闻图往往有版权限制；如果你是做线下分享 PPT，通常“资料引用”问题不大，但若要公开发布，建议优先换成 Commons、机构档案或自己截图。

## 一、暖场：当代怠工、AI、平台劳动

### 1. 办公室摸鱼 / 假装工作 / coffee break

- 用途：讲“个人化怠工”的日常形态时做开场图。
- 页面链接：[Unsplash](https://unsplash.com)
- 搜索关键词：
  - `office worker laptop coffee break`
  - `employee staring at screen office`
  - `mouse jiggler office desk`
  - 中文可搜：`办公室 摸鱼 工位 咖啡 电脑`

### 2. AI 抢走快乐、留下 CR/测试/审查

- 用途：讲 AI 改变劳动分工，保留“人做审查”的痛苦部分。
- 页面链接：[Unsplash](https://unsplash.com)
- 搜索关键词：
  - `programmer code review laptop`
  - `AI coding assistant screen`
  - `github copilot screenshot code review`
  - 中文可搜：`AI 编程 代码审查 截图`

### 3. Human-in-the-loop / 人被 agent 速度拖着走

- 用途：讲“人作为监工、确认者、背责者”。
- 搜索关键词：
  - `human in the loop dashboard`
  - `annotation workflow screen`
  - `AI monitoring dashboard operator`
  - 中文可搜：`human in the loop 工作流 截图`

### 4. 平台劳动与算法管理

- 用途：从当代外卖骑手切回“技术治理劳动”。
- 页面链接：[Delivery Couriers’ Protest](https://www.rvc.adv.br/post/artigo-breves-notas-sobre-a-subordina%C3%A7%C3%A3o-algor%C3%ADtmica-no-trabalho-em-plataformas-digitais-e-suas-res)
- 备注：这是文章页，不是档案馆文件页，但图本身很适合“平台工人集体抗争/算法管理”这一段。

### 5. 备用：韩国快递/配送工人罢工

## 二、卢德运动本体

### 6. 袜机 / Stocking frame

- 用途：解释卢德运动不是抽象反技术，而是针对具体机器。
- 页面链接：[Stocking frame](https://en.wikipedia.org/wiki/Stocking_frame)
- 备注：页面顶部就有袜机图片，适合讲东米德兰。

### 7. 卢德运动总览

- 用途：总述 1811-1816、三大战区、机器破坏。
- 页面链接：[Luddite](https://en.wikipedia.org/wiki/Luddite)
- 备注：适合当“总封面图源入口”，页面里还能继续追其他图。
