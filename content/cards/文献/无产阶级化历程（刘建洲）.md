# 无产阶级化历程：理论解释、历史经验及其启示

> 发表于核心学术期刊《社会》杂志的无产阶级化历史社会学综述论文。该文献梳理了查尔斯·蒂利的无产阶级化理论框架，并精细总结了西欧、南部非洲（阿瑞吉模型）、东亚NICs（具海根模型）以及东欧前社会主义国家（塞勒尼模型）的无产化历史变迁，为审视中国农民工阶级形成提供比较类型学。

### 本文献的核心结构与分析网络

刘建洲在这篇重磅论文中，将无产阶级化（Proletarianization）确立为审视劳工阶级形成的结构性前提，打破了阶层研究和利益群体分析的范式局限：

1. **概念与困境的重申**：
   - 区分了基于统计职业变化的“弱无产阶级化”与基于生产资料彻底剥夺的“强无产阶级化”。
   - 引介了查尔斯·蒂利的定义，强调无产阶级化是与“资本主义进展”而非单纯的“工业化”绑定，且最初发生在乡村的原初工业化中。
2. **发达国家与边缘国家的历史经验**：
   - **沃勒斯坦与阿瑞吉模型**：阐述了为什么局部的半无产阶级化更有利于资本早期积累，揭示了彻底无产化反而会抬高劳动力再生产成本的悖论。
   - **东亚模式（具海根）**：对比了欧洲手工业行会文化对阶级形成的主体性支撑，指出东亚NICs面临手工业传统缺席、国家强力压制与压缩型工业化特征。
3. **社会主义与转型国家路径**：
   - **塞勒尼模型**：聚焦匈牙利等国计划体制下的行政无产化与第二经济中“被中断的资产阶级化”轨迹之间的较量。
4. **中国农民工“半无产阶级化”困境**：
   - 结合沈原、潘毅的劳工社会学，指出在户籍与二元土地承包制下，中国农民工处于“劳动力使用与劳动力再生产空间拆分”的独特半无产化生存状态。

| 核心维度 | 理论来源 | 中国情境映射 |
| :--- | :--- | :--- |
| **弱无产阶级化** | 林宗弘 | 雇佣扩大但自雇、小农顽强存续 |
| **半无产阶级化** | 沃勒斯坦/阿瑞吉 | 承包地地权作为劳动力退守缓冲器 |
| **拆分式再生产** | 潘毅/任焰 | 宿舍劳动体制转嫁阶级代际成本 |
| **中断的资产化** | 塞勒尼 | 非正规经济、乡镇企业与小农现代化 |
