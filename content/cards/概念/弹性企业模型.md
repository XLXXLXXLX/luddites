# 弹性企业模型

> **弹性企业模型（Flexible Firm Model）**，是由英国人力研究所（IMS）学者约翰·阿特金森（John Atkinson, 1984, 1985）提出的解释晚期资本主义企业重组与用工分流的核心管理模型。该模型概括了资本主义企业为了应对80年代以来的市场剧烈波动和成本压力，如何系统性地将员工分化为“核心-边缘”两个层级，以榨取不同的灵活性。

---

## 模型结构：功能灵活性与数量灵活性

阿特金森主张，现代企业通过将劳动力结构性地划分为不同圈层，来实现对外部市场不确定性的柔性消化：

```
                    ┌──────────────────────┐
                    │      分包与自雇      │
                    │  ┌────────────────┐  │
                    │  │    边缘员工    │  │
                    │  │  ┌──────────┐  │  │
                    │  │  │ 核心员工 │  │  │
                    │  │  └──────────┘  │  │
                    │  └────────────────┘  │
                    └──────────────────────┘
```

1. **核心员工层 (Core Workers)**：
   * **特点**：享有高度就业保障、完善的培训和职业阶梯。
   * **管理目的**：获取**“功能灵活性（Functional Flexibility）”**。管理层打破传统的专业工种界限，要求这部分员工掌握多项操作或维护技术（多技能化），允许企业在不同生产工艺、任务间自由调配他们，以消除工时空隙。
2. **边缘员工层 (Peripheral Group)**：
   * **特点**：包括兼职人员、临时合同工、劳务派遣和外包自雇者。
   * **管理目的**：获取**“数量灵活性（Numerical Flexibility）”**与**“财务灵活性（Financial Flexibility）”**。他们没有就业保障，工资随劳动力市场供求和业务淡旺季波动。管理层可以根据产品订单量，随时裁撤或增补他们，使这部分边缘员工成为消化经济波动的缓冲肉盾。

## 劳动过程学派的学术祛魅

保罗·汤普森在[[cards/文献/工作的本质（汤普森）]]第八章中联合波勒特（Pollert, 1988）等学者，对这一管理学模型进行了深刻的社会学解构：

### 1. “多技能化”向“多任务化”的退化
汤普森指出，核心员工的“功能灵活性”在实践中很少意味着手艺和智能深度的提升。相反，它往往表现为**“多任务化（Multitasking）”**或**“工作范围扩大化（Work Enlargement）”**。管理层仅仅是将数个同样被去技能化的常规工序（例如：看管机器+清扫车间+填写报表）合并给同一名核心工人执行，其本质是提高劳动强度。

### 2. 阶级分层的性别与种族特征
弹性企业模型在宏观上加剧了劳动力市场的分割。极少数享有“功能灵活性”福利的核心员工多为男性白人熟练工；而承担“数量灵活性”代价、随时面临裁员风险的边缘劳动力，则高度集中了女性、青年和少数族裔工人，加剧了[[cards/论点/去技能化导致原子化而非统一意识|工人阶级的原子化与内部横向冲突]]。
