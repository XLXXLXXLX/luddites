# 《砸机器之后》图片素材库

本目录只收集候选素材，尚未修改任何幻灯片。当前共 20 张，按“历史空间与机器—行动、镇压与群众政治—当代技术劳动链”组织。

## 使用时先区分三种证据

1. **同期或近同期视觉材料**：可以帮助讨论当时人怎样描绘机器、劳动与政治，但仍需追问作者、出版目的和图像修辞。
2. **后世技术图、遗址照与纪念物**：适合解释结构、定位地点或讨论记忆，不能当成 1811—1813 年现场记录。
3. **当代场景照**：只用于把 AI 部署拆回基础设施和劳动过程，不代表某一家机构的真实案例。
