### C. 阅读核心文献

入口：[[MOC/文献地图]]。

- **文献卡片**：位于 `cards/文献/`，用于快速掌握作者、论点和关联概念。

同一作品可能同时存在上述多个版本。遇到 `full`、`readable`、`summary`、`_chunks` 或 `.pdf.md` 时，先判断它是译文、可读版、摘要、分段中间稿还是原始提取文本。

## 2. 目录地图

| 目录 | 内容定位 | 适合的使用方式 |
|---|---|---|
| `cards/` | 原子知识卡片：概念、人物、事件、文献、论点、专题 | 快速定位定义、论点和关联节点 |
| `MOC/` | 史实、理论、人物、文献四张主题地图 | 从主题而非文件名开始浏览 |
| `翻译文本/` | 中文译文、完整作品、章节译文与专题页 | 连续阅读；注意版本层级 |
| `研究笔记/` | 阅读摘要、章节总结、文献综述、比较研究 | 理解论证来源和理论背景 |
| `素材提取文本/` | 从 PDF/EPUB 等提取出的全文文本 | 检索和定位原文；需回到来源核对 |
| `讲稿与大纲/` | 分享会成稿候选、大纲、理论路线、证据地图 | 演讲生产区，也是史料审计入口 |
| `讲稿与大纲/事实核查记录/` | 按年份、事件、文书、歌曲和档案展开的证据审计 | 判断某条叙述能否使用及如何降格表述 |
| `ignored_source/` | 原始 PDF、书籍、扫描件等素材库 | 作为来源存档，不作为首选阅读入口 |
| `assets/` | 通用图片和来源信息 | 查图像来源、许可与图注 |
| `.obsidian/` | Obsidian 配置 | 通常不需要修改 |

当前工作区约有：`cards/` 116 个文件、`MOC/` 4 个文件、`研究笔记/` 17 个文件、`素材提取文本/` 77 个文件、`翻译文本/` 77 个文件、`讲稿与大纲/` 167 个文件。数量会随增删变化；不要把这些数字当作稳定元数据。

## 4. 按时间和主题浏览

- **1811—1816**：卢德运动核心时期、三大战区、毁机、纵火、审判与镇压。
- **1817—1842**：Pentrich、Swing、宪章运动、插塞暴动等后续起义与传承。
- **19—20 世纪比较**：工人阶级形成、劳动过程、国企工人、俄国与中国经验。
- **当代**：算法劳动、骑手抵抗、AI 劳动、怠工与新卢德主义。

### 主题

- 机器、技术与劳动控制

## 5. Agent 工作注意事项

1. 先读本索引，再进入具体目录；不要一开始遍历 `事实核查记录/` 或 `素材提取文本/` 的全部文件。
2. 修改讲稿前，先确定当前主线版本，再查相应的证据审计和事实核查记录。
3. 需要定义或理论关系时，优先使用 `MOC/` 和 `cards/`；需要连续论证时，再进入 `研究笔记/` 或 `翻译文本/`。
4. 处理同一作品的多个文件时，明确记录“原始提取 → 翻译 → 可读版/摘要 → 研究笔记 → 文献卡片”的关系。
5. 需要公开演示时，区分 Quartz 内容页、Reveal.js HTML 成品、幻灯片专用资源和 `content/assets/` 通用素材。
6. 不要把提取文本、机器生成草稿、报纸转录或后世口述未经核查地写成确定事实。
7. 根目录 `content/index.md` 中的旧卡片数量可能滞后；精确分类以 `cards/index.md` 和实际目录为准。
